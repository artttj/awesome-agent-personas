# 🤝 Contribution Guidelines

Thanks for helping improve **Awesome Agent Personas**.

This is a curated list, not a directory of every persona prompt on the internet. The goal is to collect projects that introduce something genuinely useful or interesting around agent identity, personality, persona distillation, cognitive cloning, memory, character consistency, or multi-agent perspectives.

## ✅ What Makes a Good Addition?

A project should demonstrate at least one meaningful idea such as:

- persistent agent identity or `SOUL.md`
- persona or personality distillation
- cognitive cloning
- character reconstruction
- memory and identity
- persona consistency or drift
- evolving personalities
- behavioral boundaries
- persona evaluation
- multi-agent cognitive perspectives
- tooling or specifications for agent identity

Preference is given to projects with a real implementation, documented methodology, research value, or an unusual approach.

## ❌ What We Usually Do Not Include

Please avoid submitting:

- generic prompt collections
- mass-generated persona dumps
- thin “You are an expert in X” prompts
- duplicate or near-duplicate projects
- projects with no useful documentation
- projects where personality is only a marketing label
- low-effort wrappers around an existing project

**Quality matters more than quantity.**

## 🌍 Non-English Projects

Non-English projects are very welcome.

However, every entry in this repository must be understandable to an English-speaking newcomer.

Please provide:

- an English project title or descriptive name
- a short English explanation
- important cultural or technical context when needed
- the original project link

Do not leave unexplained non-English terminology in the list.

## 🌟 Highlighting an Individual Persona

If a large repository contains especially interesting personas, you can also propose one for the **Highlighted Personas** section.

A highlighted persona should demonstrate a concrete technique, for example:

- unusually strong behavioral boundaries
- clear decision heuristics
- compact versus full persona variants
- relationship-aware identity
- multi-character orchestration
- evidence-backed personality construction
- an interesting way to prevent persona drift

Link directly to the persona file or persona directory whenever possible.

## ✍️ Entry Style

Keep entries concise and useful.

A good project entry looks like:

```markdown
## 🧬 Project Name

A short explanation of what the project does.

**Why it is interesting:** one or two sentences explaining the technique or idea that makes it worth exploring.

🔗 https://github.com/example/project
```

For a highlighted persona:

```markdown
| **Persona Name** | What makes the persona technically interesting. | [Open persona](https://github.com/example/project/path) |
```

Avoid marketing copy. Explain the actual technique or design choice.

## 🔎 Before Opening a Pull Request

Please check that:

- the project is not already listed
- the link works
- the repository is publicly accessible
- the project has enough documentation to understand what it does
- the description is written in clear English
- non-English concepts are translated or explained
- the description explains why the project is interesting
- the addition fits the most relevant section
- unrelated formatting changes are not included

## 📦 Pull Request Scope

Keep pull requests focused.

For a normal addition, one project or one small related group of projects per pull request is ideal.

A PR that adds a project should not also reformat unrelated sections.

## 🧭 Choosing a Section

Use the closest existing category:

- **SOUL.md and Agent Identity**
- **Persona Distillation**
- **Character and Evolving Personas**
- **Cognitive Clones**
- **Multi-Agent Personas**
- **Specifications and Tooling**
- **Collections**
- **Highlighted Personas**

If nothing fits, explain why a new category would be useful in the pull request.

## 💡 Suggesting Something Without a PR

If you found something interesting but do not want to write the entry yourself, open an issue with:

- the project URL
- a one-sentence explanation
- why you think it belongs here

## 🧹 Maintenance Contributions

Fixes are welcome too, including:

- broken links
- outdated descriptions
- renamed repositories
- archived projects
- clearer explanations
- improved English translations

Thanks for helping keep the list useful. ✨
